Cómo interpretar estas métricas

Tasa éxito: porcentaje de movimientos donde el operador entregó una salida distinta, válida y dentro del rango de similitud de turbulencia contra el componente actual.

Cobertura: porcentaje de movimientos donde la estrategia generó al menos un candidato antes del filtro semántico final.

Similitud prom.: similitud coseno SBERT promedio entre el candidato seleccionado y el componente original, calculada sobre los movimientos con candidato válido y agregada entre las K repeticiones.

Tiempo prom.: tiempo promedio por aplicación del operador. El valor wall muestra el tiempo real observado con el paralelismo configurado.

Fidelidad final: similitud semántica SBERT, por coseno, entre cada texto final generado y el texto de referencia configurado.

Diversidad final: diversidad semántica entre los textos finales generados por la misma estrategia, calculada como 1 menos la similitud coseno promedio contra los demás textos finales.

Deltas: diferencia contra el baseline sin turbulencia usando las mismas métricas finales. Un delta positivo indica mejora respecto al baseline.

Costo relativo: índice heurístico adimensional para ordenar costo del operador. Menor es mejor; no representa dinero ni milisegundos puros. Fórmula: llamadas LLM x 1000 + inferencias DistilBERT x 10 + textos embebidos x 1 + consultas WordNet x 0,2 + consultas PPDB reales x 0,2 + segundos acumulados del operador x 5.

PPDB: si el índice PPDB no está preparado, la tarjeta superior indica no disponible. En la tabla se muestran consultas PPDB reales; los intentos de usar PPDB como respaldo se reportan separado como intentos no disponibles.
